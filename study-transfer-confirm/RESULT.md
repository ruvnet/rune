# Confirmation: Better within the frozen sorting contexts

Frozen memory succeeded in 154/288 fresh input cases (53.47%, Wilson 95% [47.70%, 59.15%]). Uniform random achieved an expected 35.53% [30.23%, 41.22%]; training selected counting achieved 106/288 (36.81%) [31.44%, 42.52%]. Other fixed algorithms achieved 33.68% radix and 36.11% unstable.

Memory cleared the frozen >=10 percentage point margins and interval separation gates. Paired case and seed-block Monte Carlo sign-flip p values were about 0.00001 at 100000 draws for both controls, below the preregistered 0.0125 thresholds. All 24 seed blocks favored memory. Memory matches the original seven training records exactly. All 864 confirmation reports passed independent source, contract, holdout and evaluator digest checks.

This is input transfer within twelve synthetic sorting contexts on one shared host. Feature metadata was supplied by the harness. It does not establish general compiler improvement, algorithm invention or autonomous discovery. The earlier pilot remains NoDifference, and the original kernel study remains Insufficient.
